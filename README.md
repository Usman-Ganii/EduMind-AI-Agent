🎓 EduMind AI | Student Workspace

Your Intelligent AI-Powered Learning Companion

EduMind AI is an AI-powered student productivity and learning platform designed to make studying smarter, faster, and more interactive.

Built with Python and Streamlit, and powered by Google's Gemini API, EduMind AI helps students understand concepts, summarize study materials, generate quizzes, and organize their academic activities in one place.

✨ Key Features

- AI Study Chat: Ask academic questions and get intelligent, easy-to-understand explanations.
- PDF Summarizer: Upload PDF documents and generate concise summaries of study materials.
- Quiz Generator: Create AI-generated quizzes to test your knowledge and improve learning.
- Study Planner: Organize study activities and manage your learning schedule.
- Interactive Dashboard: Access learning tools through a clean and user-friendly interface.
- AI Integration: Powered by Google Gemini for intelligent responses and content generation.

🛠️ Tech Stack

Technology| Purpose
Python| Core programming language
Streamlit| Web application and UI
Google Gemini API| AI-powered responses
Google GenAI SDK| Gemini API integration
PyPDF| PDF text extraction
TOML| Secure API configuration
